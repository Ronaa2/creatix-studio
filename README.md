# Creatix Studio — Portfolio v4

Les projets sont cliquables et ouvrent une fenêtre de détail.
La section contact donne accès à Instagram et YouTube. Instagram est le canal recommandé pour écrire au studio.

Réseaux :
- https://www.instagram.com/creatix_studio.fr/
- https://youtube.com/@creatixstudiofr

Administration : ouvrez `admin.html` pour modifier les projets. Les descriptions détaillées sont éditables et s'affichent dans la fenêtre de détail.
L'administration utilise le stockage local du navigateur : elle n'est pas sécurisée et n'est pas synchronisée entre visiteurs.

Captures à placer dans `assets/projects/` : timood.png, spingo.png, homespace.png, waterly.png.
Logo : `assets/logo-creatix.png`.
